# Agent notes for antedom

antedom is a website engine: valid-HTML templates where logic lives in
`ante:` attributes and expressions are JavaScript (sobek), evaluated at
build time before any DOM exists. Design thesis: if you know the web
platform, you know antedom — prefer web-native primitives and small
incremental tiers over bespoke concepts.

## Where the truth lives

- Directive reference: the package doc comment in [antedom.go](antedom.go).
- Subsystem docs: the doc comment atop each file — [layout.go](layout.go)
  (composition), [scope.go](scope.go), [shortcode.go](shortcode.go),

## Layout

Single flat Go package at the repo root. `cmd/antedom` is the CLI
(`new`, `build`, `serve`). `testsites/` generates synthetic projects for
benchmarks (never checked in). `docs/antedom.js` is the docs site's own
extension (sitemap/RSS outputs).

## Commands

```sh
go run ./cmd/antedom serve --site docs   # 127.0.0.1:26833, live-reloads content
go run ./cmd/antedom build --site docs -o out
go test ./...
air                                      # dev loop; rebuilds on .go changes (see README)
```

## Constraints to respect

- `serve` is intended for **production** serving, not just previews:
  design serve features with production semantics (it renders per
  request; serve and build must produce byte-identical output).
- Sobek runtimes are not goroutine-safe; one Engine renders one page at
  a time, and every serve request gets its own runtime.
- Output is serialized from the parsed tree: well-formed by
  construction, all interpolation contextually escaped. Don't add paths
  that emit raw strings into documents.
- We record benchmarks, but they are generated by the host OS, and agents always run in containers,
  perhaps in macOS Docker Desktop meaning a VM.
  Feel free to run your own benchmarks, but for historical comparison you'll need to ask the user to run one outside the container.
  Described in [design/benchmarks/index.md](docs/pages/design/benchmarks/index.md).
  The benchfmt config keys in [benchconfig_test.go](benchconfig_test.go) are an append-only schema.
